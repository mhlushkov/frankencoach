## Jury questions

**"What if the model writes a harmful test?"**
The test runs in a separate process, a static scan allows only computation, with no network, no files and no environment, the member must say yes before every new tool, and any tool can be forgotten with one command.

**"Why not just prompt per sport?"**
A grown tool is tested code: it is reused for free, it survives a restart, and it can tell you exactly what the camera did not see.

**"What does it not do?"**
It sees in 2D with one camera, it gives no medical clearance and it makes no diagnosis.
